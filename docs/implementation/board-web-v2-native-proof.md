No acepta URL, key, cookie, cabecera ni acción. Las promesas revalidan generación; retirarla antes de que una copia pendiente termine impide republicar. El store verifica revisión/manifiesto/hashes SHA256 propios mediante MessageDigest, archivo 256 KiB, bundle 1 MiB y reserva 8 MiB total antes de decodificar assets. Máximo 32 generaciones/snapshots. Todo es memoria privada, sin caché persistente.

API24/25 no se identifican por API pública getCurrentWebViewPackage: causa explícita provider_identity_unavailable, sin hidden API ni inferir paquete.
